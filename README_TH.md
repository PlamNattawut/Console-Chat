# Console Chat - โปรแกรมแชทผ่าน Terminal สุดคลาสสิก

**Console Chat** คือโปรแกรมแชทแบบเรียลไทม์ (Real-time Chat Application) ที่ทำงานผ่านหน้าจอ Command Line (Terminal) โดยถูกออกแบบมาให้มีความเสถียรสูง รองรับการเชื่อมต่อที่หลากหลาย และมีระบบคัดกรองผู้ใช้งานที่เข้มงวด เพื่อให้ประสบการณ์การแชทเป็นไปอย่างราบรื่นและปลอดภัย

---

## ✨ ฟีเจอร์เด่น (Key Features)

### 1. 🌐 ยืดหยุ่นทุกการเชื่อมต่อ (Flexible Networking)
ตัวโปรแกรมถูกออกแบบมาให้รองรับการเชื่อมต่อได้ถึง 3 ระดับ โดยผู้ใช้ไม่ต้องตั้งค่าอะไรให้วุ่นวาย:
- **Localhost:** สำหรับทดสอบระบบแบบรันเครื่องเดียว
- **LAN / WiFi:** พิมพ์แค่ IP Address ของเพื่อนในวงแลนเดียวกัน ระบบจะเชื่อมต่อให้ทันที
- **Ngrok (Global Access):** รองรับการแชร์เซิร์ฟเวอร์ข้ามโลกผ่านระบบ Tunneling (Ngrok) โดยระบบจะปรับโปรโตคอลความปลอดภัยเป็น `wss://` ให้อัตโนมัติ

### 2. 🛡️ ระบบคัดกรองสุดเนี้ยบ (Advanced Validation System)
เราให้ความสำคัญกับสังคมในแชทที่น่าอยู่ ระบบจึงมี "ด่านตรวจคนเข้าเมือง" ที่เขียนด้วย **Regular Expression (Regex)** กว่า 10 ด่าน:
- **กันคนก่อกวน:** ป้องกันการสแปมคีย์บอร์ดมั่วๆ (Gibberish) เช่น `asdf`, `qwer` หรือพยัญชนะติดกันยาวๆ
- **กันการแอบอ้าง:** แบนคำสงวนอย่าง `admin`, `system`, `root` รวมถึงดักจับคนที่พยายามเลี่ยงบาลีด้วยตัวเลข (Leetspeak) เช่น `adm1n`
- **กัน UI พัง:** บังคับใช้เฉพาะภาษาอังกฤษและตัวเลขในการตั้งชื่อ เพื่อป้องกันหน้าจอ Terminal แสดงผลผิดเพี้ยนจากภาษาไทยหรืออีโมจิ (แต่ยังสามารถพิมพ์ภาษาไทยในช่องแชทได้ตามปกติ)
- **กันอักษรล่องหน:** ป้องกัน Zero-width spaces ที่คนชอบใช้ส่งแชทเปล่าๆ เพื่อป่วนระบบ

### 3. 🏓 ระบบเคลียร์คนค้าง (Ping-Pong Heartbeat)
บอกลาปัญหา "Zombie Connection" หรือผู้เล่นปิดหน้าจอหนีแล้วชื่อค้างในระบบ! 
เซิร์ฟเวอร์ของเรามีระบบ **Application-Level Ping-Pong** ที่จะคอยส่งสัญญาณเช็คสถานะลูกข่ายทุกๆ 10 วินาที หากใครหลุดการเชื่อมต่อ หรือกดปิดโปรแกรมดื้อๆ (Ctrl+C) ระบบจะรับรู้และเตะชื่อนั้นออกจากเซิร์ฟเวอร์ทันที เพื่อคืนพื้นที่และชื่อให้ผู้ใช้คนอื่น

### 4. 🧪 เสถียรภาพระดับใช้งานได้
โครงสร้างโค้ดทั้งหมด (Services, Validation, Messaging) ถูกเขียนขึ้นบนมาตรฐานสูงสุด โดยมีการทำ Automated Test (Unit Testing) ครอบคลุมทุกการทำงานหลักและ Edge Cases (กรณีสุดวิสัย) มากกว่า 100+ เคส เพื่อการันตีว่าระบบจะไม่มีวันล่มแม้เจอข้อมูลขยะ

## 🛠️ เทคโนโลยีที่ใช้เบื้องหลัง (Tech Stack)

* **Language:** TypeScript (Strict Mode) เพื่อโครงสร้างโค้ดที่แข็งแรงและลดบั๊ก
* **Runtime & Test Runner:** Bun 🚀 (ทำงานเร็วกว่า Node.js และมีตัวรันเทสต์ในตัว)
* **WebSocket:** ไลบรารี `ws` สำหรับรับส่งข้อมูลแบบ Real-time ขุมพลังหลักของแชท

## 🚀 วิธีติดตั้งและรันโปรแกรม (Getting Started)

### ขั้นที่ 1: รันเซิร์ฟเวอร์ (เปิดศูนย์กลางแชท)
เปิด Terminal ขึ้นมาแล้วพิมพ์คำสั่งนี้ เพื่อเปิดรอรับแขกที่พอร์ต `8080`:
```bash
bun run .\src\server\index.ts
```

### ขั้นที่ 2 (ทางเลือก): เปิดอุโมงค์ Ngrok 
หากต้องการให้เพื่อนที่อยู่คนละบ้านเข้ามาเล่นได้ ให้เปิด Terminal อีกหน้าต่างแล้วพิมพ์:
```bash
ngrok http 8080
```
*(จากนั้นก๊อปปี้ลิงก์ที่ Ngrok ให้มา เอาไปส่งให้เพื่อน)*

### ขั้นที่ 3: เข้าสู่ระบบแชท (Client)
เปิด Terminal บานใหม่ (หรือฝั่งเครื่องเพื่อน) แล้วพิมพ์:
```bash
bun run .\src\index.ts
```
ระบบจะถามหา **Server IP**:
- ถ้าเล่นเครื่องเดียว: **กด Enter ผ่านได้เลย**
- ถ้าเล่นผ่าน LAN: **พิมพ์ IP เครื่องแม่** (เช่น `192.168.1.45`)
- ถ้าเล่นผ่าน Ngrok: **วางลิงก์ Ngrok** ลงไปได้เลย

จากนั้นตั้งชื่อ Username แล้วเริ่มแชทได้ทันที! 🎉
