# Console Chat - Test Suite

ไดเรกทอรีนี้ประกอบด้วยชุดทดสอบ (Unit Tests) สำหรับตรวจสอบความถูกต้องของ Logic และดักจับ Edge Cases ทั้งหมดของระบบ Console Chat

## ข้อตกลงในการทำงาน (Rules of Engagement)

**⚠️ ห้ามแก้ไขไฟล์ Test โดยเด็ดขาด**

ไฟล์ชุดทดสอบทั้งหมดในไดเรกทอรีนี้ถูกเขียนขึ้นมาเพื่อเป็นมาตรฐานการทำงานของระบบ ห้าม "ลักไก่" ด้วยการเข้าไปลบ แก้ไข หรือคอมเมนต์โค้ดในไฟล์ `.test.ts` เพื่อหลอกให้เทสผ่าน

**แนวทางการแก้ปัญหา:**
1. ให้ยึดผลลัพธ์และ Error Message ที่ได้จากการรันเทสเป็นหลัก
2. เมื่อพบเทสที่ไม่ผ่าน (Fail) หน้าที่ของคุณคือไปค้นหาและ **แก้ไขโค้ดหลักในโฟลเดอร์ `src/` เท่านั้น**
3. แก้ไข Source Code จนกว่าระบบจะทำงานได้ตรงตามเงื่อนไขที่กำหนดไว้ในเทส

## คำสั่งสำหรับรันเทส

ใช้คำสั่งนี้ที่โฟลเดอร์ root ของโปรเจกต์ เพื่อตรวจสอบสถานะของระบบ:

```bash
bun run test
```

เป้าหมายคือการเคลียร์ข้อผิดพลาด (Fail) ทั้งหมดให้กลายเป็น Pass (สีเขียว) โดยที่ไฟล์ทดสอบยังคงสภาพเดิม 100%
